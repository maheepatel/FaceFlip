## 1. Custom image FaceFlip (the "make your own deck" mode)

Let anyone build a FaceFlip game from their own pictures.

- Upload a few images, for example NFTs from a project you hold or love.
- Each image is cut into 4 quarters, and those quarters become the sides of the blocks.
- The cards are the full images, or mixes of quarters from different images, and players race to rebuild them.
- Share the custom game with a link so friends or a whole community can play it.

### Web3 touch (later)
- Connect a wallet and pull NFT images straight from a collection.
- A project could launch a branded FaceFlip for its holders.
- Possible extras: holder-only rooms, leaderboards per collection, and rewards for winners.

### Matching note
This still uses the current exact matching method: each slot is stored as "which picture and which way it is turned" and compared directly, never by comparing pixels. Custom quarters only need a fixed upright direction so a turned quarter counts as wrong.

## 2. Kido: a collection of kids' and fun games

**Kido** (or **Kidi**) is a small, funny brand for a collection of browser games, each inspired by an offline game: toys, board games, party games and playground games.

- FaceFlip is game #1.
- Each new game takes a physical or offline game, studies its real rules, and rebuilds it as an original digital game with its own art and names.
- The same base for all of them: works on phone, tablet and desktop, bots to play against, online 1v1 with a link, same screen mode, and simple modes for little kids.
- One home page that lists all the Kido games.

### Name options
- **Kido** (first choice)
- **Kidi**
- Others to consider: Kiddo Box, Giggly, Bonk

### Next steps when we pick this up
1. Choose the final name and check the domain and GitHub name.
2. Make a list of offline games to bring online next.
3. Decide whether FaceFlip moves under the Kido brand or stays as its own repo.
